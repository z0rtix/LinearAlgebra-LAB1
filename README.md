2. Краткое описание алгоритмов 
2.1. Метод Гаусса 
 
Метод Гаусса состоит из двух этапов: 
1. Прямой ход – приведение матрицы к верхнетреугольному виду.   
   Для каждой строки row выбирается диагональный элемент pivot. Затем для всех строк i 
ниже текущей вычисляется коэффициент factor = A[i][row] / pivot, и из i-й строки 
вычитается текущая строка, умноженная на factor. Аналогичные преобразования 
выполняются с вектором правой части b. 
2. Обратный ход – последовательное нахождение неизвестных снизу вверх.   
   Из последнего уравнения находится последняя неизвестная, затем, поднимаясь вверх, – 
остальные. 
 
 
2.2. Метод Гаусса с выбором ведущего элемента 
 
В отличие от базового метода, на каждом шаге прямого хода перед исключением 
выполняется частичный выбор: В текущем столбце (начиная с текущей строки) ищется 
элемент с максимальным по модулю значением. Если максимальный элемент находится 
не в текущей строке, соответствующие строки матрицы и вектора b меняются местами. 
После этого прямой ход продолжается стандартным образом. 
 
Выбор ведущего элемента повышает численную устойчивость метода, особенно при 
работе с плохо обусловленными матрицами, так как позволяет избежать деления на очень 
маленькие числа. 
 
 
2.3. LU-разложение 
 
Матрица A представляется в виде произведения двух треугольных матриц:   
A = L · U,   
где: 
• L – нижнетреугольная матрица с единицами на главной диагонали, 
• U – верхнетреугольная матрица. 
 
 
После получения такого разложения решение системы A · x = b сводится к двум шагам: 
1. Прямая подстановка: решение системы L · y = b (тривиально, так как L – 
треугольная). 
2. Обратная подстановка: решение системы U · x = y. 
 
Главное преимущество метода – возможность однократного разложения при 
многократном решении систем с одинаковой матрицей, но разными правыми частями. 
Трудоёмкая часть (разложение, O(n³)) выполняется один раз, а решение каждой 
дополнительной системы (подстановки) требует всего O(n²) операций.

4. Результаты экспериментов 
 
4.1.   Сравнение времени для одной системы 
 
Для размеров n = 100, 200, 500, 1000 измерялось время решения одной системы методом 
Гаусса без выбора, методом Гаусса с выбором и LU-разложением (отдельно разложение и 
подстановки, а также суммарное время). 
 
Таблица 1. Время решения одной системы (секунды): 
=== СРАВНЕНИЕ ВРЕМЕНИ ДЛЯ ОДНОЙ СИСТЕМЫ === 
 
n         Gauss              GaussPivot      LU total        LU decomp       LU solve 
100     0.002093        0.002244        0.001882        0.001839        0.000043 
200     0.019367        0.019629        0.015438        0.015255        0.000183 
500     0.262126        0.277075        0.294928        0.293887        0.001041

Анализ:   
• Для небольших размеров (n ≤ 200) все методы работают сопоставимо быстро.   
• При n = 1000 метод Гаусса (особенно без выбора) оказывается быстрее LU-
разложения примерно в 2,3 раза. Это объясняется тем, что LU-разложение требует 
дополнительных операций для заполнения матрицы L и имеет бóльшие накладные 
расходы. 
 
 
4.2. Множественные правые части 
 
Зафиксирован размер матрицы n = 500. Для k = 1, 10, 100 правых частей сравнивалось 
общее время решения всех систем методом Гаусса с выбором (каждая система решается 
заново) и методом LU (однократное разложение + подстановки для каждой правой части).

Анализ:   
• При k = 1 метод Гаусса немного быстрее (0.32 с против 0.37 с).

выполняется один раз, а каждая подстановка (O(n²)) требует значительно меньше 
времени.

5. Выводы 
 
1.   По скорости: 
• Для решения одной системы метод Гаусса (особенно без выбора) работает быстрее 
LU-разложения, так как не требует дополнительных операций по заполнению 
матрицы L. 
• При решении множества систем с одинаковой матрицей LU-разложение 
демонстрирует значительное преимущество. В эксперименте при k = 100 ускорение 
составило 64 раза по сравнению с методом Гаусса. 
 
2.   По точности: 
• На плохо обусловленных матрицах (матрица Гильберта) выбор ведущего 
элемента позволяет уменьшить относительную ошибку (при n = 15 ошибка 
снижена с 3.37 до 2.92). Это подтверждает важность частичного выбора для 
повышения численной устойчивости. 
 
3.  Невязка во всех экспериментах остаётся близкой к нулю, что свидетельствует 
о корректной реализации алгоритмов. 
 
4.  Практические рекомендации: 
• Если требуется решить одну систему – можно использовать метод Гаусса (проще и 
быстрее). 
• Если требуется решить много систем с одинаковой матрицей – оптимален подход 
на основе LU-разложения. 
• При работе с плохо обусловленными матрицами необходимо применять метод с 
выбором ведущего элемента.
